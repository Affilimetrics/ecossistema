# Conectores externos

Esta versão inclui apenas o contrato abstrato `MarketplaceConnector`. Nenhuma integração real com Magalu, Mercado Livre, Amazon ou Shopee está ativa. Para ativar uma integração, implementar autenticação oficial, paginação, limites, atualização de status, sincronização incremental e testes com credenciais autorizadas. Não presumir endpoints nem usar scraping como substituto de API autorizada.
